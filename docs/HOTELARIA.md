# Diretriz visual — NEXUS Hotelaria

## Conceito

A identidade combina hospitalidade e tecnologia por meio de uma paleta quente, elegante e de alto contraste controlado. O laranja queimado representa acolhimento e energia; o vermelho vinho transmite profundidade e sofisticação; o cobre atua como destaque premium.

## Paleta

| Uso | Cor | Código |
|---|---|---|
| Ação principal | Laranja queimado | `#C65A11` |
| Profundidade e sidebar | Vermelho vinho | `#8B1E2D` |
| Hover e ação intensa | Laranja intenso | `#E56A1F` |
| Destaques premium | Cobre | `#D89A32` |
| Fundo geral | Cinza quente | `#F7F4F2` |
| Superfície | Branco | `#FFFFFF` |
| Texto principal | Grafite | `#1F2937` |
| Texto secundário | Marrom acinzentado | `#6B5B55` |
| Bordas | Bege rosado suave | `#E5D6CE` |

## Regras de aplicação

- Usar o gradiente laranja–vinho apenas em destaques, cabeçalhos especiais e indicadores principais.
- Manter cards predominantemente brancos para preservar legibilidade.
- Reservar o cobre para ícones, etiquetas VIP, avaliações e detalhes premium.
- Utilizar vermelho em alertas operacionais apenas quando houver risco ou pendência real.
- Estados de sucesso permanecem verdes, seguindo o padrão funcional global do NEXUS.
- A estrutura dos componentes não muda; somente a camada visual do portfólio é adaptada.
